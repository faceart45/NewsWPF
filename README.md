## Реализация

* **Архитектура:** Проект переведен на паттерн MVVM. Логика разделена на три слоя: Models (данные), ViewModels (бизнес-логика и команды), Pages (XAML-разметка).
* **Авторизация:** Реализован модуль входа с проверкой учетных данных (`editor` / `news2025`).
* **Управление новостями:** 
  * Таблица новостей (`DataGrid`) с колонками: ID, Заголовок, Категория, Дата, Автор, Просмотры, Статус.
  * Полный CRUD (создание, чтение, редактирование, удаление).
  * Валидация полей ввода (длина, допустимые символы, дата). При ошибках поля подсвечиваются красной рамкой, а кнопка сохранения блокируется.
  * Счетчик просмотров увеличивается при двойном клике по строке.
* **Управление категориями:** 
  * Отдельная вкладка с таблицей категорий.
  * Вычисляемое поле «Количество новостей» обновляется автоматически.
  * Защита от удаления категорий, содержащих новости.
* **Интерфейс:** Использован `TabControl` для разделения потоков, применены единые стили кнопок и полей ввода.

## Изменения относительно исходного варианта

* **Переход к MVVM:** Вся бизнес-логика и обработчики событий вынесены из code-behind (`.xaml.cs`) в классы `ViewModel`. Взаимодействие View и ViewModel происходит через команды (`ICommand`), а не через события `Click`.
* **Исправление генерации ID:** В исходном коде использовался `static int Id`, из-за чего все объекты имели одинаковый идентификатор. Реализован уникальный ID для каждого объекта через приватный статический счетчик `_nextId`.
* **Уведомление об изменениях:** Во все модели (`News`, `Category`, `Users`) добавлена реализация интерфейса `INotifyPropertyChanged`. Теперь интерфейс автоматически обновляется при изменении данных в коде.
* **Исправление краша при авторизации:** В первой версии закрытие окна авторизации завершало работу всего приложения. Исправлено путем переназначения `Application.Current.MainWindow` на главное окно и установки `ShutdownMode="OnLastWindowClose"`.
* **Доработка главного окна:** Пустая заготовка `NewsWindow` из исходника заменена на полноценный интерфейс с вкладками, таблицами и панелью управления.
* **Добавление валидации:** В исходном варианте проверка данных отсутствовала. Реализована строгая валидация согласно ТЗ с визуальной обратной связью для пользователя.
* **Безопасность типов:** Код адаптирован под включенный `Nullable enable` в .NET 10 (добавлены проверки на `null` и инициализация полей по умолчанию).
